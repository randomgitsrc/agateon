# docs/research/ —— 客观机制调查报告

放**客观技术事实**的调查报告：某个平台/工具/机制"实际怎么运作"，靠 CLI 帮助、官方文档、二进制内省、端到端实测等交叉核实得出。

与其它目录的分工：

- **本目录**：客观机制，**不含决策**。结论标注证据强度（`[实测]` / `[文档]` / `[--help]` / `[自述]` / `[内省]` / `[推断]`）。
  - **本目录的例外与边界**：`agateon-value-assessment-20260929.md` 是**评估类**报告，其 §6 给出**由证据导出的方向**——
    那**不是决策**（不构成立项/取舍），**落地决策一律走 `docs/design-notes/` 与 `agate-workspace/roadmap/`**。
    该报告的强度标注沿用其自身图例（`可复核` / `不可复核` / `⚠️`），与上表 `[实测]` 等价的对应是：
    **`可复核` ≙ `[实测]`；`不可复核` ≙ `[自述]`**；凡无法复核者该报告已就地标注，不得单独引用。
- `docs/design-notes/`：决策记录（讨论过什么、否决了什么、采纳了什么、为什么）。设计里的机制事实**引用**本目录，不重复抄。
- `agate/platform-notes.md`：协议本体的平台适配**权威源**（精简能力矩阵 + Windows 安装）。本目录的报告**feed 进**它，不合并进它。
